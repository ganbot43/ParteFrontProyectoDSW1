# Apple Store Web

Aplicación web para una tienda virtual tipo Apple Store, desarrollada como proyecto académico.

## Tecnologías
- C#
- ASP.NET Core MVC
- HTML, CSS, JavaScript
- Bootstrap
- Tailwind CSS

## Funcionalidades
- Registro e inicio de sesión de clientes
- Visualización de productos
- Carrito de compras
- Proceso de compra
- Panel administrativo básico

## Descripción
Aplicación web que consume una API REST para gestionar las operaciones de una tienda virtual, incluyendo compras, carrito y administración.

## Integración
Consume la API REST desarrollada en el repositorio backend del proyecto.

## Nota
Se utilizaron frameworks de estilos como Bootstrap y Tailwind CSS para el diseño de la interfaz.
